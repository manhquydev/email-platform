## Migration Path

### From cPanel Native
1. Keep existing accounts during transition
2. Set up Ephemera tenant per customer
3. Migrate mailboxes via IMAP
4. Update DNS records
5. Disable cPanel email

### From Google/Zoho
1. Create Ephemera tenant
2. Export via Google Takeout / Zoho export
3. Import via IMAP migration tool
4. Update MX records
5. Cancel previous subscription

### From Self-Hosted
1. Create Ephemera tenant
2. Direct IMAP migration
3. Update DNS
4. Decommission servers
